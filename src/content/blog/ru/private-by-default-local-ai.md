Большинство AI-инструментов по умолчанию отправляют данные на сервер. Для рыночной
станции — где ключи, позиции и стратегии и есть вся игра — такой стандарт перевёрнут.
Nexow инвертирует его: **приватность по умолчанию, локальность по замыслу.**

Вот что это реально означает.

## Codegen с собственным ключом, в браузере

В приватном режиме вы добавляете свой API-ключ Anthropic, и генерация виджетов
выполняется на стороне клиента. Когда вы запрашиваете виджет, запрос идёт из
браузера в Anthropic с вашим ключом — не через инфраструктуру Nexow.
Неаутентифицированная сессия ничего нам не стоит, потому что нечего запускать:
работа происходит на вашей машине.

## Ваши виджеты живут в браузере

Каждый созданный виджет, каждая версия, каждый лог и вся библиотека виджетов
сохраняются в **IndexedDB** браузера. Доступны офлайн и не привязаны к аккаунту.
Очистите хранилище — и они исчезнут: серверной копии нет, потому что загрузки на
сервер никогда не было.

## Прямые подключения к venues

Где политика CORS venue позволяет, Nexow подключается к нему **напрямую из
браузера**, полностью обходя наш proxy. Учётные данные биржи используются для
общения с биржей — не с нами. Меньше прыжков — ниже задержка и меньше поверхность
доверия.

## Почему приватность по умолчанию важна

- **Безопасность.** Чем меньше сторон касаются ваших ключей, тем меньше мест, где
  они могут утечь. Local-first полностью убирает нас из цепочки в приватном режиме.
- **Задержка.** Прямые подключения пропускают сетевой прыжок — это важно, когда вы
  смотрите на order book.
- **Владение.** Ваши дашборды — ваши. Без lock-in, без танцев с экспортом — они
  живут на вашей машине.
- **Стоимость.** Вы платите только за собственное использование модели, без наценки
  и без подписки, необходимой для работы на canvas сегодня.

## Компромиссы — честно

Local-first не без компромиссов. Некоторые venues не допускают прямых подключений из
браузера и идут через тонкий proxy. Локальная персистентность означает, что работа
привязана к профилю браузера, пока вы не выберете синхронизацию. Собственный ключ —
управление собственным использованием. Мы считаем, что это правильные компромиссы
для инструмента так близко к вашим деньгам.

По мере добавления hosted-планов, trading agents и серверных компонентов принцип
остаётся неизменным: **ваши ключи, ваши данные, ваша машина** — пока вы явно не
выберете облако.
