이제 전문가 수준의 암호화폐 대시보드를 만들려면 개발자일 필요가 없습니다.
Nexow 같은 AI-native 빌더를 사용하면 원하는 위젯을 일상 언어로 설명하고
자유로운 캔버스에 실시간으로 동작하는 차트를 얻을 수 있습니다. 몇 분 만에
완전한 암호화폐 워크스테이션을 만드는 방법은 다음과 같습니다.

## 만들게 될 것

하나의 캔버스에서 암호화폐 페어를 처음부터 끝까지 추적합니다:

1. 이동평균이 있는 캔들스틱 차트
2. 오더북 깊이 뷰
3. 무기한 계약용 펀딩 레이트 모니터
4. 관련 페어의 컴팩트 워치리스트

## 1단계 — 앱을 열고 프라이빗 모드 선택

[Nexow를 실행](https://x.nexow.ai)하고 설정에서 자신의 Anthropic API 키를
추가하세요. 프라이빗 모드에서는 위젯 생성이 브라우저에서 완전히 실행되며
서버로 아무것도 전송되지 않습니다 — 자신의 API 사용량에 대해서만 비용을
지불합니다.

## 2단계 — 메인 차트 요청

보고 싶은 내용을 입력하세요:

> Coinbase의 BTC-USD 캔들스틱 차트, 1시간봉, EMA 20과 50, 거래량 막대.

Nexow가 위젯을 생성하고 Coinbase 커넥터에 연결한 뒤 캔버스에 배치합니다.
가격이 실시간으로 스트리밍됩니다.

## 3단계 — 오더북 깊이 추가

두 번째 위젯을 만드세요:

> Deribit의 BTC-PERP 오더북 깊이 차트, 각 측 상위 50레벨.

크기를 조정해 차트 옆에 배치하세요. 이제 가격 움직임과 유동성을 나란히 볼 수
있습니다.

## 4단계 — 펀딩 레이트 모니터링

무기한 계약 트레이더는 펀딩으로 살고 죽습니다. 다음과 같이 요청하세요:

> Binance 상위 10개 무기한 계약의 현재 펀딩 레이트 테이블, 절대값 기준 정렬,
> 매분 새로고침.

## 5단계 — 캔버스 정리

위젯을 자신에게 맞는 레이아웃으로 드래그하고, 관련 뷰를 워크스페이스로
그룹화하세요 — BTC용, 메이저용, 리서치용. 즉시 전환할 수 있습니다.

## 자주 묻는 질문

**코딩을 알아야 하나요?** 아니요. 자연어로 위젯을 설명하면 Nexow가 작성하고
실행합니다. 코드를 읽을 수 있다면 모든 위젯의 소스를 검사할 수 있습니다.

**어떤 거래소를 지원하나요?** Nexow는 Binance, Coinbase, Kraken, Deribit,
BitMEX 등과 함께 FX, 주식, 예측 시장 venue를 포함해 20개 이상의 커넥터를
제공합니다.

**내 데이터는 프라이빗한가요?** 예. 프라이빗 모드에서는 codegen이 브라우저에서
실행되고, 위젯은 IndexedDB에 로컬로 저장되며, 많은 venue는 브라우저에서 직접
연결됩니다 — 따라서 키와 데이터는 사용자의 기기에 남습니다.

**비용은 얼마인가요?** 프리뷰는 무료이며, 프라이빗 모드에서는 자신의 Anthropic
API 사용량에 대해서만 비용을 지불합니다.
