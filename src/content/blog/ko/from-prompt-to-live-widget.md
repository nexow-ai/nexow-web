트레이딩 대시보드를 만드는 것은 항상 같은 반복이었습니다: API 찾기, 문서 읽기,
websocket 다루기, payload 정규화, 차트 라이브러리 선택, 레이아웃과 씨름하기,
관심 있는 모든 상품에 대해 반복. Nexow는 그 전체 루프를 한 문장으로
접습니다.

프롬프트를 입력하고 캔버스에 라이브 위젯이 나타날 때까지 실제로 일어나는
일은 다음과 같습니다.

## 1. 보고 싶은 것을 설명

프롬프트는 자연어일 뿐입니다:

> Coinbase의 BTC-USD 캔들스틱 차트에 EMA 20과 50, 아래에 RSI 패널을 보여줘.

배울 스키마도, 설정 파일도 없습니다. 결과 — 상품, venue, 지표, 레이아웃 — 을
동료에게 설명하듯 설명합니다.

## 2. Nexow가 위젯 소스를 생성

Nexow는 Anthropic SDK를 통해 Anthropic의 Claude 모델에 프롬프트를 내며,
필요한 컨텍스트와 함께: 사용 가능한 커넥터, 반환 데이터 형태, 위젯이 만족해야
하는 runtime contract. Claude가 위젯의 실제 소스 코드 — fetch logic, transforms,
rendering — 을 작성합니다.

모델이 고정 템플릿을 채우는 것이 아니라 실제 코드를 쓰기 때문에, 만들 수
있는 범위는 열려 있습니다: 오더북 깊이 차트, 펀딩 레이트 히트맵, 상관 행렬,
커스텀 신호, 단순 테이블. 설명할 수 있다면 Nexow가 보통 만들 수 있습니다.

## 3. 위젯은 sandbox에서 실행

생성된 코드는 강력하므로 엄격한 경계 뒤에서 실행됩니다. 모든 위젯은 격리된
iframe 안에서 실행됩니다: UI를 렌더링하고 필요한 데이터를 가져올 수 있지만,
워크스페이스에 접근하거나 다른 위젯을 읽거나 주어지지 않은 것에 닿을 수
없습니다. 위험 없는 파워.

## 4. 라이브 데이터는 커넥터를 통해 유입

위젯은 실제 데이터가 있어야 유용합니다. Nexow는 FX, 크립토, 주식, 선물, 옵션,
예측 시장을 아우르는 20개 이상의 플러그 가능한 커넥터를 제공합니다 — OANDA,
Binance, Coinbase, Kraken, Interactive Brokers, Polygon, Kalshi, Polymarket
등. 위젯은 지정한 venue를 구독하고 가격, 오더북, 참조 데이터가 바로
스트리밍됩니다.

venue의 CORS policy가 허용하는 곳에서는 해당 호출이 **브라우저에서 직접**
실행되며 서버를 거치지 않습니다 — 지연 시간을 낮추고 자격 증명을 사용자의
기기에 둡니다.

## 5. 일상 언어로 다듬기

첫 생성이 마지막인 경우는 드뭅니다. 모든 것은 대화로 편집 가능합니다:
*"EMA 200 추가"*, *"로그 스케일로 전환"*, *"펀딩 레이트로 캔들 색칠"*. Nexow가
위젯을 제자리에서 다시 쓰고, 변경을 버전 관리하며, 검사하거나 롤백할 수 있는
로그를 유지합니다.

## 왜 중요한가

아이디어에서 차트까지의 전통적 경로는 시간으로 측정됩니다. Nexow에서는
초 단위이며, 얻는 결과물은 검사 가능한 실제 위젯 — 블랙박스가 아닙니다.
대시보드가 스스로 조립되고, 코드, 데이터, 키를 계속 통제합니다.
