Een paar weken geleden zeiden we dat agents eraan kwamen: AI met een volledig
harnas die zelfstandig kijkt, redeneert en handelt. Vandaag zijn ze er. Je kunt
een agent bouwen, hem tools geven, **hem naar de cloud deployen** en toekijken
terwijl hij werkt — volgens schema, met je tabblad gesloten.

Dit is wat we hebben geleverd.

## Het harnas, nu met een deploy-knop

Een agent in Nexow is meer dan een prompt. Je stelt hem samen uit een
**harnas** — model, geheugen, vaardigheden, tools, kennis en triggers — in een
visuele bouwer. Dat deel heb je misschien al gezien. Nieuw is de laatste stap:
**Deploy**.

Deployen maakt een momentopname van je agent en geeft die aan de cloudruntime
van Nexow. Vanaf dat moment draait hij op zijn eigen pulsslag — elke 15
minuten, elk uur, dagelijks, welk ritme je ook instelt — zonder dat je browser
open is. Je kunt hem ook handmatig aanstoten met **Nu uitvoeren** wanneer je
een run buiten het schema om wilt.

## Tools worden verleend, niet verondersteld

Een agent raakt alleen aan wat jij hem laat aanraken. Elke tool in zijn harnas
zit achter een **expliciete toestemming**: jij bepaalt of hij je verbindingen
mag lezen, meldingen mag plaatsen, naar widgets mag schrijven, enzovoort. Geen
toestemming, geen toegang — de agent ziet de tool letterlijk niet.

Dat maakt het veilig om een agent een echte taak te geven. Een bot zegt je dat
BTC 5% daalde; een agent kan worden opgedragen om *het orderboek en het
financieringspercentage te controleren wanneer dat gebeurt, en op te schrijven
wat hij vond* — met precies de toegang die jij hebt goedgekeurd.

## Geheugen tussen runs

Agents behouden **geheugen** over runs heen. Wat je agent tijdens de run van
maandag leerde, is er dinsdag nog steeds — zodat hij een stelling door de tijd
kan volgen, veranderingen opmerkt in plaats van momentopnamen opnieuw te
beschrijven, en werk overslaat dat al gedaan is.

## Elke run, vastgelegd

Gedeployde agents houden een **tijdlijn van runs** bij: wanneer elke run
startte, of hij netjes eindigde, faalde of werd overgeslagen, en wat er
binnenin gebeurde — live gestreamd terwijl de run loopt. Open een willekeurige
run om het volledige gesprek te lezen: wat de agent zag, welke tools hij
aanriep en wat hij concludeerde. Hapert een bovenliggend model, dan belandt
ook dat in de geschiedenis, benoemd als wat het is, geen mysterie.

Je houdt de hele tijd de controle: **pauzeer** een agent, **hervat** hem,
deploy een bijgewerkt harnas opnieuw, of haal hem met **undeploy** volledig
offline. Je abonnement bepaalt hoeveel agents je tegelijk gedeployd kunt
houden.

## Nog steeds standaard privé

Het principe is niet verschoven: de cloud is iets waar je voor kiest. Een
harnas bouwen kost niets en raakt geen server; deployen is een expliciete
keuze per agent, en privémode pauzeert cloudruns in plaats van ze stilletjes
door te laten draaien.
