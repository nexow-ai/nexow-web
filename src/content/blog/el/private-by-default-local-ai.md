Τα περισσότερα εργαλεία AI αποστέλνουν τα δεδομένα σας σε έναν διακομιστή από προεπιλογή. Για έναν σταθμό εργασίας αγοράς — όπου τα κλειδιά, οι θέσεις και οι στρατηγικές σας είναι ολόκληρο το παιχνίδι — η προεπιλογή είναι ανάποδα. Nexow την αναστρέφει: **ιδιωτική από προεπιλογή, τοπική κατά σχεδιασμό.**

Εδώ είναι τι αυτό πραγματικά σημαίνει.

## Φέρτε τα δικά σας κλειδί codegen, στο πρόγραμμα περιήγησης

Σε ιδιωτική λειτουργία προσθέτετε το δικό σας κλειδί Anthropic API και η δημιουργία widget εκτελείται από την πλευρά του πελάτη. Όταν ζητάτε ένα widget, η αίτηση πηγαίνει από το πρόγραμμα περιήγησής σας στη Anthropic με το κλειδί σας — όχι μέσω της υποδομής Nexow. Μια ανέξουσιοδοτη σεάνس κοστίζει μας τίποτα να τρέξει γιατί δεν υπάρχει τίποτα να τρέξει: η εργασία συμβαίνει στη μηχανή σας.

## Τα widget σας ζουν στο πρόγραμμα περιήγησής σας

Κάθε widget που δημιουργείτε, κάθε έκδοση, κάθε αρχείο καταγραφής και ολόκληρη η βιβλιοθήκη widget σας διατηρούνται στη **IndexedDB** του προγράμματος περιήγησής σας. Είναι διαθέσιμα χωρίς σύνδεση και δεν είναι δεσμευμένα σε κανέναν λογαριασμό. Σβήστε το χώρο αποθήκευσης και έφυγαν — δεν υπάρχει αντίγραφο στη σερβερ μαδιάδας επειδή δεν ήταν ποτέ μια ανάρτηση στη σερβερ.

## Άμεσες συνδέσεις με τοποθεσίες

Όπου η πολιτική CORS της τοποθεσίας το επιτρέπει, η Nexow συνδέεται σε αυτήν **απευθείας από το πρόγραμμα περιήγησής σας**, παρακάμπτοντας πλήρως τη σύνδεσή μας. Τα διαπιστευτήριά σας ανταλλαγής χρησιμοποιούνται για να μιλήσουν στην ανταλλαγή — όχι για να μιλήσουν σε εμάς. Λιγότερα άλματα σημαίνει χαμηλότερη καθυστέρηση και ένα μικρότερο επιφάνεια εμπιστοσύνης.

## Γιατί ιδιωτικό από προεπιλογή σημαίνει

- **Ασφάλεια.** Όσο λιγότερο μέρη που αγγίζουν τα κλειδιά σας, τόσο λιγότερα μέρη που μπορούν να διαφύγουν. Το τοπικό-πρώτο μας αφαιρεί από το μονοπάτι εντελώς σε ιδιωτική λειτουργία.
- **Καθυστέρηση.** Άμεσες συνδέσεις παραλείπουν ένα άλμα δικτύου, κάτι που σημαίνει όταν παρακολουθείτε ένα βιβλίο παραγγελιών.
- **Ιδιοκτησία.** Οι πίνακες ελέγχου σας είναι δικοί σας. Χωρίς κλείδωμα, χωρίς χορό εξαγωγής — ζουν στη μηχανή σας.
- **Κόστος.** Πληρώνετε μόνο για τη δική σας χρήση του μοντέλου, χωρίς σήμανση και χωρίς συνδρομή που απαιτείται για κτίσιμο στο canvas σήμερα.

## Οι συναλλαγές, ειλικρινά

Το τοπικό-πρώτο δεν είναι χωρίς συναλλαγές. Ορισμένες τοποθεσίες δεν επιτρέπουν άμεσες συνδέσεις του προγράμματος περιήγησης και πρέπει να δρομολογήσουν μέσω ενός λεπτού διακομιστή μεσολάβησης. Η τοπική επιμονή σημαίνει ότι η εργασία σας είναι δεσμευμένη σε ένα προφίλ προγράμματος περιήγησης έως ότου επιλέξετε να συγχρονίσετε. Και η λειτουργία του δικού σας κλειδιού σημαίνει τη διαχείριση της δικής σας χρήσης. Πιστεύουμε ότι αυτές είναι οι σωστές συναλλαγές για ένα εργαλείο που κάθεται τόσο κοντά στα χρήματά σας.

Καθώς προσθέτουμε hosted σχέδια, trading agents και server components, η αρχή παραμένει σταθερή: **τα κλειδιά σας, τα δεδομένα σας, η μηχανή σας** — εκτός αν επιλέξετε ρητά να εισέλθετε στο cloud.
