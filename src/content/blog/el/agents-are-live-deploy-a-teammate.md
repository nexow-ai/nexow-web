Πριν από λίγες εβδομάδες είπαμε ότι έρχονται τα agents: AI με ένα πλήρες
harness που παρακολουθεί, συλλογίζεται και δρα μόνο του. Σήμερα είναι εδώ.
Μπορείτε να φτιάξετε έναν agent, να του δώσετε εργαλεία, να τον **κάνετε
deploy στο cloud** και να τον βλέπετε να δουλεύει — σε χρονοδιάγραμμα, με το
tab σας κλειστό.

Δείτε τι κυκλοφόρησε.

## Το harness, τώρα με κουμπί deploy

Ένας agent στη Nexow είναι κάτι περισσότερο από ένα prompt. Τον
συναρμολογείτε από ένα **harness** — μοντέλο, μνήμη, δεξιότητες, εργαλεία,
γνώση και ενεργοποιητές — σε έναν οπτικό builder. Αυτό το κομμάτι ίσως το
έχετε ήδη δει. Το νέο είναι το τελευταίο βήμα: το **Deploy**.

Το deploy παίρνει ένα στιγμιότυπο του agent σας και το παραδίδει στο cloud
runtime της Nexow. Από εκεί και πέρα τρέχει με τον δικό του παλμό — κάθε 15
λεπτά, ανά ώρα, καθημερινά, σε όποιον ρυθμό ορίσετε — χωρίς να είναι ανοιχτό
το πρόγραμμα περιήγησής σας. Μπορείτε επίσης να τον τρέξετε χειροκίνητα με το
**Run now** όποτε θέλετε ένα πέρασμα εκτός προγράμματος.

## Τα εργαλεία παραχωρούνται, δεν θεωρούνται δεδομένα

Ένας agent αγγίζει μόνο ό,τι του επιτρέπετε να αγγίξει. Κάθε εργαλείο στο
harness του περνά από **ρητή έγκριση**: εσείς αποφασίζετε αν μπορεί να
διαβάζει τις συνδέσεις σας, να στέλνει ειδοποιήσεις, να γράφει σε widgets
και ούτω καθεξής. Χωρίς έγκριση δεν υπάρχει πρόσβαση — ο agent κυριολεκτικά
δεν βλέπει το εργαλείο.

Αυτό κάνει ασφαλές το να αναθέσετε σε έναν agent μια πραγματική δουλειά. Ένα
bot σας λέει ότι το BTC έπεσε 5%· σε έναν agent μπορείτε να πείτε να
*ελέγξει το βιβλίο εντολών και το ποσοστό χρηματοδότησης όταν συμβεί, και να
συντάξει τι βρήκε* — χρησιμοποιώντας ακριβώς την πρόσβαση που εγκρίνατε.

## Μνήμη ανάμεσα στις εκτελέσεις

Οι agents κρατούν **μνήμη** από εκτέλεση σε εκτέλεση. Ό,τι έμαθε ο agent σας
στο πέρασμα της Δευτέρας είναι ακόμα εκεί την Τρίτη — ώστε να παρακολουθεί
μια θέση μέσα στον χρόνο, να εντοπίζει αλλαγές αντί να περιγράφει ξανά
στιγμιότυπα, και να παραλείπει δουλειά που έχει ήδη κάνει.

## Κάθε εκτέλεση, καταγεγραμμένη

Οι deployed agents κρατούν ένα **χρονολόγιο εκτελέσεων**: πότε ξεκίνησε κάθε
εκτέλεση, αν ολοκληρώθηκε καθαρά, απέτυχε ή παραλείφθηκε, και τι συνέβη μέσα
της — μεταδιδόμενο ζωντανά όσο η εκτέλεση τρέχει. Ανοίξτε οποιαδήποτε
εκτέλεση για να διαβάσετε ολόκληρη τη συνομιλία: τι είδε ο agent, ποια
εργαλεία κάλεσε και σε τι κατέληξε. Αν ένα upstream μοντέλο σκοντάψει, κι
αυτό καταγράφεται στο ιστορικό, με την ετικέτα αυτού που πραγματικά είναι,
όχι ως μυστήριο.

Παραμένετε σε έλεγχο σε όλη τη διαδρομή: κάντε **παύση** σε έναν agent,
**συνεχίστε** τον, κάντε ξανά deploy ένα ενημερωμένο harness ή κάντε τον
**undeploy** εντελώς. Το πλάνο σας ορίζει πόσους agents μπορείτε να
διατηρείτε deployed ταυτόχρονα.

## Ακόμα ιδιωτικό από προεπιλογή

Η αρχή δεν έχει μετακινηθεί: το cloud είναι κάτι που επιλέγετε εσείς. Το να
χτίσετε ένα harness δεν κοστίζει τίποτα και δεν αγγίζει κανέναν διακομιστή·
το deploy είναι ρητή επιλογή ανά agent, και η ιδιωτική λειτουργία παύει τις
εκτελέσεις στο cloud αντί να τις συνεχίζει σιωπηλά.
