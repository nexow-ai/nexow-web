Η Nexow κατασκευάστηκε για να τρέξει στη μηχανή σας. Σε ιδιωτική λειτουργία προσθέτετε το δικό σας κλειδί Anthropic, η δημιουργία widget εκτελείται από την πλευρά του πελάτη και διατηρείτε τα πάντα στον τοπικό αποθηκευτικό χώρο — χωρίς λογαριασμό, τίποτα δεν αποστέλλεται στους διακομιστές μας. Αυτό είναι η προεπιλογή και δεν πρόκειται να φύγει.

Αλλά μερικές φορές θέλετε τα dashboards σας σε κάθε συσκευή, πιστώσεις χωρίς να συνδέσετε ένα κλειδί και μια κοινότητα για να κτίσετε στο πλάι. Αυτό είναι αυτό που ξεκλειδώνει ένας **δωρεάν λογαριασμός**.

## Ακόμα ιδιωτική από προεπιλογή

Ένας λογαριασμός είναι πάντα *προαιρετικός*. Μπορείτε να συνεχίσετε τη δημιουργία 100% τοπικής για όσο θέλετε — δώστε τα δικά σας κλειδί codegen, IndexedDB persistence, άμεσες συνδέσεις με τοποθεσίες, ολόκληρη το τοπικό πρώτο στοίβα. Η εγγραφή δεν αλλάζει αυτό. απλώς προσθέτει ένα δικτυακό στρώμα στο πάνω μέρος όταν το θέλετε.

## Τι προσθέτει ένας δωρεάν λογαριασμός

Δημιουργήστε έναν λογαριασμό — χωρίς πιστωτική κάρτα — και παίρνετε:

- **10.000 δωρεάν πιστώσεις AI** κατά την εγγραφή, ώστε να μπορείτε να δημιουργήσετε widget χωρίς να προσφέρετε το δικό σας κλειδί.
- **Συγχρονισμό cloud σε πολλές συσκευές** για τα δεδομένα εργασίας σας και τα widget σας — ξεκινήστε στο desktop σας, παίξτε το στο φορητό σας.
- **Το δίκτυο κατασκευαστή** — ο κοινοτικός τροφοδότης, η αγορά και μια κοινή βιβλιοθήκη widget, καθώς αυτές οι δυνατότητες κυλιούνται.
- **XP και αμοιβές** καθώς δημιουργείτε, μοιράζεστε και δημοσιεύετε.

## Συγχρονισμό cloud, χωρίς να χάσετε την ιδιοκτησία

Ο συγχρονισμός είναι opt-in και ανά χώρο εργασίας. Αυτό που συγχρονίζετε ζει στο cloud ώστε να σας ακολουθεί ανά συσκευή. αυτό που διατηρείτε τοπικά παραμένει τοπικό. Αποφασίζετε πού ζει κάθε dashboard — δεν υπάρχει διακόπτης σε όλα ή τίποτα και χωρίς εξαγωγή χορό για να πάρετε την εργασία σας πίσω.

## Το on-ramp στο δίκτυο

Ένας δωρεάν λογαριασμός είναι το on-ramp από *κτίσιμο μόνο* σε *κτίσιμο με άλλους*: ακολουθήστε τους κατασκευαστές, δυο-dashboards, δημοσιεύστε widget και — σύντομα — εγγραφείτε σε ελεγχόμενα σήματα στρατηγικής. Επιλέγετε πόσο από το δίκτυο που θέλετε, ένα βήμα κάθε φορά.
