几周前我们说 agents 即将到来：配备完整工具链、能自主监控、推理并行动的 AI。今天它们来了。你可以构建一个 agent、交给它工具、**将它部署到云端**，然后看着它工作 — 按计划运行，标签页关闭也不停。

以下是这次交付的内容。

## 工具链，现在有了部署按钮

Nexow 中的 agent 不只是一段提示词。你在可视化构建器中用 **harness（工具链）** 组装它 — 模型、记忆、技能、工具、知识和触发器。这部分你可能已经见过。新增的是最后一步：**Deploy（部署）**。

部署会为你的 agent 生成一份快照，交给 Nexow 的云端运行时。从那一刻起，它按自己的心跳运行 — 每 15 分钟、每小时、每天，节奏由你设定 — 无需浏览器保持打开。想在计划之外跑一次？随时用 **Run now** 手动触发。

## 工具靠授权，而非默认拥有

Agent 只能触及你允许它触及的东西。工具链中的每个工具都受 **授权门控**：能否读取你的连接、发送通知、写入组件等等，都由你决定。没有授权就没有访问 — agent 根本看不到那个工具。

这让把真正的工作交给 agent 变得安全。Bot 告诉你 BTC 跌了 5%；agent 则可以被指示 *在那一刻检查订单簿和资金费率，并把发现写成总结* — 使用的正是你亲手批准的那些权限。

## 跨运行的记忆

Agents 在多次运行之间保留 **记忆**。周一那次运行学到的东西，周二依然在 — 因此它可以长期跟踪一个论点、察觉变化而不是反复描述快照，并跳过已经做过的工作。

## 每次运行，都有记录

已部署的 agents 保留一条 **运行时间线**：每次运行何时开始、是顺利完成、出错还是被跳过，以及内部发生了什么 — 随运行执行实时流式呈现。打开任意一次运行即可阅读完整对话：agent 看到了什么、调用了哪些工具、得出了什么结论。如果上游模型出了状况，也会如实记入历史，标注为它本来的样子，而不是一个谜。

全程由你掌控：**暂停** agent、**恢复** 它、重新部署更新后的工具链，或者彻底 **取消部署**。你的套餐决定可以同时保持部署的 agent 数量。

## 依然默认私密

原则没有变：云端始终是你主动选择加入的。构建工具链不花一分钱、不触碰任何服务器；部署是针对每个 agent 的明确选择，而私密模式会暂停云端运行，而不是悄悄继续。
