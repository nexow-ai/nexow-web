你不再需要是开发者，也能搭建专业级的加密货币仪表盘。借助 Nexow 这类 AI 原生构建工具，用自然语言描述你想要的组件，即可在自由画布上获得实时运行的图表。下面介绍如何在几分钟内搭建一套完整的加密货币工作站。

## 你将搭建什么

一块画布，端到端跟踪一个加密货币交易对：

1. 带移动平均线的 K 线图
2. 订单簿深度视图
3. 永续合约资金费率监控
4. 相关交易对的紧凑观察列表

## 步骤 1 — 打开应用并选择私密模式

[启动 Nexow](https://x.nexow.ai)，在设置中添加你自己的 Anthropic API 密钥。在私密模式下，组件生成完全在浏览器中运行，不会向我们的服务器发送任何内容 — 你只需为自己的 API 用量付费。

## 步骤 2 — 生成主图表

输入你想看到的内容：

> 来自 Coinbase 的 BTC-USD K 线图，1 小时 K 线，带 20 和 50 EMA 以及成交量柱。

Nexow 会生成组件，将其连接到 Coinbase 连接器，并放置在画布上。价格实时流入。

## 步骤 3 — 添加订单簿深度

创建第二个组件：

> Deribit 上 BTC-PERP 的订单簿深度图，每侧前 50 档。

调整大小并放在图表旁边。现在你并排查看价格走势和流动性。

## 步骤 4 — 监控资金费率

永续合约交易者离不开资金费率。输入：

> 一张表格，显示 Binance 上前 10 大永续合约的当前资金费率，按绝对值排序，每分钟刷新。

## 步骤 5 — 排布画布

将组件拖入符合你习惯的布局，把相关视图分组到工作区 — 一个用于 BTC，一个用于主流币，一个用于研究。随时即时切换。

## 常见问题

**我需要会编程吗？** 不需要。你用自然语言描述组件，Nexow 负责编写并运行。如果你会看代码，每个组件的源码都可以查看。

**支持哪些交易所？** Nexow 内置 Binance、Coinbase、Kraken、Deribit、BitMEX 等连接器，以及外汇、股票和预测市场场所 — 总计 20 多个。

**我的数据是私密的吗？** 是的。在私密模式下，代码生成在浏览器中运行，组件保存在本地 IndexedDB 中，许多场所直接从浏览器连接 — 因此你的密钥和数据都留在本机。

**费用是多少？** 预览免费；在私密模式下，你只需支付自己的 Anthropic API 用量。
